# 中興大學校園公告與獎學金爬蟲

自動蒐集國立中興大學的校園活動、演講、研習及獎學金公告，整理成 JSON，方便個人查閱。

## 蒐集內容

### 校園活動
- 惠蓀講座
- 圖書館活動
- 自主學習系統
- 研習暨演講活動報名系統

### 獎學金
- 蒐集獎學金名稱、承辦單位、金額、申請期限及官方公告連結
- 保留完整申請條件、年級／科系限制、所得或財產條件及應備文件
- 另外標示資格判斷：可能符合、不符合、待確認
- 不符合資格的公告仍會保留，不會直接刪除
- 資格判斷以公告文字為準；有疑義時標示待確認，申請前仍應查看正式簡章

## 資料檔案

- `data/activities.json`：校園活動資料
- `data/scholarships.json`：獎學金資料

## 自動更新

使用 GitHub Actions 定期執行爬蟲並提交資料更新。排程觸發時間可能受 GitHub Actions 排程延遲影響，不保證每次都在整點執行。

## 資料來源

- [中興大學自主學習系統](https://selfstudy.nchu.edu.tw/)
- [中興大學學務處獎學金公告](https://www.osa.nchu.edu.tw/osa/laa/scholarship.html)
- 惠蓀講座、圖書館活動及研習暨演講活動報名系統（程式中保存各來源網址）

## 注意事項

- 本專案供個人使用。
- 資料以學校及各承辦單位的最新正式公告為準。
- 爬蟲可能因網站改版、驗證機制或網路問題而暫時無法取得資料。
- 重複公告可先保留，避免誤刪不同場次或更新版本。
